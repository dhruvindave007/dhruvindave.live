Problem

Rename a column, change a type or a function signature, and something breaks somewhere else: an API route, a dashboard, a test, a doc, a migration. grep misses dynamic uses, type checkers ignore SQL, config and docs, and AI assistants edit whatever they like with no proof the change is complete or stayed in scope.

Approach

IBM Bob is the only AI in the product. Bob Shell runs headless on the server with cost, turn and time caps, and every agent is its own Bob process: Bob Fixer edits files, Bob Inspector reviews the result, and Bob Cartographer finds links the parser misses.

Governance is the point. An agent can only touch the file its permit names; anything else it changes is reverted, and a failed type check rolls the edit back before a human ever sees it.

System DNA opened real draft pull requests through its own GitHub App on a sample marketplace dashboard, and its impact engine is covered by 21 passing tests.
