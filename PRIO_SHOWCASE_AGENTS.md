# Prio portfolio landing page

Prio is an internal product. The public portfolio hosts one static landing page under `/prio/`. It describes AI Entry, human review, and the team's workflow. Keep the public page free of demo controls, sign-in links, private URLs, sample accounts, and production data. Keep domain configuration outside landing-page changes.

Use product source only to validate public-facing workflow descriptions. For local browser checks, follow `prio/README.md`. The optional installer in `scripts/install-design-skills.sh` fetches the upstream design references.
